命令说明

群聊默认需要先通过 AstrBot 唤醒：@机器人、适配器唤醒词，或回复机器人。私聊默认可直接发。
唤醒后发送 help / 帮助 / 命令说明，会自动回复命令说明。

查自己时默认使用发送者 QQ。
查别人可用真实 @某人，或把 QQ 放在命令最前面，例如 123456 b50。
支持 username 的命令也可把水鱼 username 放在最后，例如 b50 ayang。

目标写法：
@某人 b50、b50 @某人、13+分数列表 @某人 2 都可以。
QQ号 命令 表示查这个 QQ，例如 123456 我要上分。
命令 username 表示查水鱼 username，例如 13+定数表 ayang。
QQ 只支持放最前面；命令后面的纯数字通常按页码、名次、曲目 ID 或 username 理解。
今日舞萌额外支持 QQ 放最后。
rank / musicrank 只能在群聊使用；查指定玩家时用真实 @某人 或前置 QQ。
